# Media sources

Project media under `public/media/projects/` comes from repositories owned by
Giacomo Cappelletto, except for the TickIT cover below.

## Deskinator

Source repository: `deskinator-code`

- Project design, implementation, testing, and case-study authorship are
  attributed to Giacomo Cappelletto.
- `prototype.webp` was extracted from page 10 of
  `210 Final Presentation - Deskinator.pdf`.
- `boundary-discovery.webp` and `coverage-path.webp` are web exports of the
  repository's simulated boundary and coverage traces.
- `coverage-inset-distribution.webp` and `runtime-distribution.webp` are web
  conversions of `deliverables/images/distribution-coverage-inset.png` and
  `deliverables/images/distribution-time.png`.
- `deskinator-final-design-report.pdf` is an unchanged copy of
  `deliverables/deskinator-a1-group8-report.pdf` (17 pages).
- `deskinator-final-assembly-cad.pdf` is an unchanged copy of
  `deliverables/images/cad-final.pdf` (one page).
- `electronics-wiring.webp` and `final-assembly-cad.webp` are web exports of
  wiring and CAD artifacts from the same project deliverables.

- `projects/tickit/concert-crowd.webp`: "crowd-and-lights-at-a-concert" from
  [Good Free Photos](https://www.goodfreephotos.com/people/crowd-and-lights-at-a-concert.jpg.php),
  released under CC0 / public domain.
