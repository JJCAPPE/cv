# GE Vernova outreach research package

**Research cut-off:** 22 August 2026

This folder contains a source-audited build-before-outreach strategy for GE Vernova’s Cambridge, Massachusetts and Niskayuna, New York technical cluster.

## Files

- [`ge-vernova-research-brief.md`](./ge-vernova-research-brief.md) — complete 20-section recommendation, role matrix, organizational map, project selection, technical specification, evaluation plan, network strategy, calendar, work-authorization analysis, and source appendix.
- [`sources.md`](./sources.md) — normalized registry of 55 first-party, authoritative, historical, and candidate sources with direct links, dates, evidence tiers, and caveats.
- [`verification-log.md`](./verification-log.md) — material corrections, completeness checks, automated validation results, and residual unknowns.

## Selected artifact

**GridShift-NE: Forecast Robustness and Datacenter–BESS Decision-Regret Benchmark**

The two-week MVP is intentionally numerical:

1. versioned EIA/NOAA data;
2. strong seasonal, statistical, and LightGBM baselines;
3. one pinned time-series foundation model;
4. rolling-origin and event-conditioned evaluation;
5. controlled missing/delayed-input tests;
6. a clearly synthetic datacenter-load scenario;
7. constrained battery dispatch;
8. forecast-to-decision regret;
9. a deterministic CLI and static technical report.

The governed analytical agent is a later extension, not the MVP.
