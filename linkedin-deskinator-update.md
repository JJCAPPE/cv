# LinkedIn Deskinator Update

## Featured Project

**Deskinator - Robotics Autonomy / Sensor-Driven Coverage**

Autonomous tabletop-cleaning robot built in Python on Raspberry Pi. The system reads APDS9960 proximity sensors, stepper odometry, and optional IMU data to detect table edges, infer a rectangular workspace, generate boustrophedon coverage paths, command motors/vacuum hardware, and log telemetry for simulation-based performance analysis.

**Tech:** Python, NumPy, Raspberry Pi, APDS9960, MPU-6050, RANSAC, coverage planning, telemetry, simulation testing

## Project Bullets

- Built Python robotics software for an autonomous desk-cleaning robot, connecting proximity sensing, odometry, boundary discovery, coverage planning, and actuator control.
- Implemented edge-event filtering with debounce/hysteresis, RANSAC rectangle fitting, inset boustrophedon lane generation, swept-area tracking, telemetry logging, and repeated-trial simulation analysis.
